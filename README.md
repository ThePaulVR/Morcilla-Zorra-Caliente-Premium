# esalert-gc.github.io
Simulador educativo de ES-Alert para Gran Canaria. Eres jefe/a de guardia de Emergencias: interpreta el radar y los avisos ficticios de AEMET y 112 Canarias, decide cuándo y a qué municipios alertar, afronta las reacciones en redes y defiende tu gestión en la rueda de prensa. Juego web en desarrollo, sin datos reales.
